Learnings:
<header> tag is there to wrap everything that is a part of header, even the Navigation Tag.
<h1> tag or any heading tag is NOT wrapped in <p> tag
for each section, instead of adding new <div> tag, add <section> tag
<p> cannot contain <h2>, <ul>, <figure>, etc.
Footer belongs inside <body>
No unnecessary <br> between paragraphs
Only one <h1>
<figure> VS <img>, img is used when it is related to the content, if it is not then we use Figure to add any image. it is used as a section seperator.
